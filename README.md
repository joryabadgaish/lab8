# lab8
## KNN Classification Project

This project uses the K-Nearest Neighbors (KNN) algorithm to classify data.

### Steps
- Loaded and explored the dataset  
- Visualized data using Seaborn  
- Scaled features using StandardScaler  
- Split data into training (70%) and testing (30%)  
- Trained KNN model (k=1)  
- Evaluated using confusion matrix and classification report  
- Tested multiple K values to find the best one (~31)  
- Retrained model with optimal K  

### Tools
Python, Pandas, Seaborn, Matplotlib, Scikit-learn  

### Conclusion
Scaling and choosing the right K improved the model accuracy.
